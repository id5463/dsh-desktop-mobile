# DSH Desktop & Mobile

Нативный десктопный GUI + удалённое управление с Android для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) — open-source ИИ-агента для программирования, где *всё является плагином*.

> Сообщество-проект, а не официальный продукт DeepSeek.

## Что вы получаете

| | Десктопное приложение | Android-приложение |
|---|---|---|
| Что это | Нативное окно Electron вокруг официального Web-интерфейса DSH | Удалённое управление вашим DSH откуда угодно |
| Установка | Ноль настройки: автоматически ставит Node.js + DSH при первом запуске (с индикатором прогресса) | Установите APK и отсканируйте QR-код |
| Удалённо | Короткий код + QR-сопряжение, авто-проброс портов UPnP, WebRTC P2P | Авто-обнаружение в LAN + удалённый доступ через интернет |

### Десктоп

- **Запуск без настройки**: если Node.js или DSH отсутствует, приложение автоматически скачает и установит их (с индикатором прогресса). Двойной клик — и готово.
- **Полный Web-интерфейс DSH** в нативном окне: системный трей, перезапуск сервера, переключение языка (中文 / English).
- **Общий доступ по LAN**: приложение проксирует DSH в вашу LAN (HTTP + WebSocket) и анонсирует его через mDNS, так что телефон находит его автоматически.
- **Удалённое сопряжение**: откройте окно подключения — там короткий код (без префикса `dsh-`) и QR-код. Отсканируйте его приложением на телефоне.
- **Удалённый доступ без настройки**: приложение может автоматически пробросить порт на роутере через UPnP и опубликовать ваш публичный IP, так что телефон в интернете подключится напрямую, не трогая настройки роутера.
- **Запасной вариант WebRTC P2P**: если прямой доступ невозможен, автоматически устанавливается зашифрованный P2P-канал (с запасным TURN-релеем).

### Android

- Отсканируйте QR-код или введите короткий код из десктопного приложения.
- Авто-обнаружение десктопов в той же Wi-Fi сети (mDNS).
- Полный Web-интерфейс DSH на телефоне: запускайте задачи, следите за прогрессом агента, одобряйте вызовы инструментов, отправляйте уточнения.
- Работает через интернет по P2P/релею — без регистрации, без аккаунта, без настройки.

## Быстрый старт

### Десктоп

Требование: Node.js ≥ 18 (приложение также может само подготовить среду выполнения).

```bash
cd desktop
npm install
npm start
```

При первом запуске приложение проверяет DSH, при необходимости скачивает (индикатор прогресса) и открывает Web-интерфейс.

### Android

Возьмите готовый APK из `android/dist/dsh-mobile-debug.apk` и установите вручную (разрешите «установку из неизвестных источников»), либо соберите сами:

```powershell
cd android
.\build-apk-aapt.ps1    # создаёт dist/dsh-mobile-debug.apk, без Android Studio/Gradle
```

Откройте приложение → в окне подключения десктопа показаны код + QR → отсканируйте телефоном → подключено.

## Как работает удалённое подключение

1. Десктоп генерирует короткий код (например, `K7X9`) и показывает QR.
2. Сигнализация идёт по MQTT (по умолчанию бесплатный публичный брокер; можно указать оба приложения на свой брокер).
3. Телефон и десктоп согласуют WebRTC-соединение; если оба за NAT, их соединяет проброс портов UPnP или TURN-релей.
4. Трафик идёт напрямую (или через релей) — без аккаунта, без регистрации.

### Примечание об ограничениях портов у провайдеров

Приложение работает в обычных проводных и мобильных сетях. Некоторые мобильные операторы (например, сеть China Mobile в материковом Китае) прозрачно перехватывают или блокируют **нестандартные входящие порты**; в такой сети прямое входящее соединение может быть отклонено. Это политика оператора, а не ограничение приложения — в таких сетях используйте подключение по LAN, другого оператора или укажите оба приложения на свой MQTT/TURN-сервер.

## Безопасность

Удалённый доступ открывает ваш локальный DSH в сеть. Десктопное приложение включает удалённые функции только при открытии окна подключения; в этой ранней версии при запуске предпринимается попытка UPnP-проброса порта для доступа из интернета за роутером — убедитесь, что доверяете своей сети, и рассмотрите отключение в публичных окружениях. Планируется слой аутентификации на основе токенов.
